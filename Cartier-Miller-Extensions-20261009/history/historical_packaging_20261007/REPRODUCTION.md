# Reproduce the consolidated extension

Python 3.10 or later is sufficient for the repaired prototype and the fresh checks; no installed third-party package is required. Run these commands from the package root, preserving the directory layout.

```bash
python verify_handover.py
python research/depth_three_recognition_20261007/core/cli.py --p 73 --short 4 16
python research/depth_three_recognition_20261007/core/cli.py --p 73 --f 1 4 0 37 --cm --unbounded-sign-test --mu 9
python research/depth_three_recognition_20261007/core/cli.py --p 73 --f 1 4 0 37 --trusted-trace 10 --verify-sign --mu 9
python research/depth_three_recognition_20261007/core/cli.py --p 73 --short 16 27 --through-depth-two
```

The first curve is recognized with (e,√2,r)=(21,41,42) and multiplier 15. The cubic returns H=10, K=55 and T=3. The last command returns `not_in_implemented_families` for a retained example in the deferred depth-three B=0-seed chain, rather than claiming non-reachability.

The default CM route uses a 64-draw cap; `--max-sign-trials k` selects another positive cap. The unbounded flag repeats until a decisive witness, with expected raw draw count at most five under the theorem's independent-uniform-randomness assumption. Neither route uses an automatic deterministic fallback. Supplied traces without `--verify-sign` retain an explicit caller-trust status; with verification, the returned record retains the point witness.

These commands regenerate validation files and their source hashes:

```bash
python research/depth_three_recognition_20261007/core/validate_depth_three.py
python research/depth_three_recognition_20261007/core/validate_consolidation.py
python research/depth_three_recognition_20261007/theory/check_integer_invariants_depth3.py
```

The first command independently compares all nonsingular short models at the ten recorded primes, coefficient pairs, twists, normalized cubics and branch sums. Its PARI checks are optional and their availability is recorded. Without PARI, large-prime trace values are not independently confirmed by PARI, and large-prime K values are not expanded except where the CSV explicitly records recurrence checks. The second command verifies finite proof certificates with a separate group-law implementation, validates the raw-x sampler on small representatives and tests failure/status paths. The third reproduces all integer invariants with standard-library arithmetic.

Validation files may change their environment records when regenerated, so the release's SHA256SUMS.json will then describe the original snapshot rather than the regenerated bytes. Historical raw files and reports remain under `historical_validation/` and `independent/`. The optional inherited `derive_family.py` and `verify_transport.py` need Sympy; they were not rerun in this environment. The ordinary Python validators and exact-integer invariant script were rerun. Elapsed validation time is not a benchmark.
