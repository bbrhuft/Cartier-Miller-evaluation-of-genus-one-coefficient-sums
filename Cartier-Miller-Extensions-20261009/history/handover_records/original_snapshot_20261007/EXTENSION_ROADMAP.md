# Extension research roadmap

These are research questions, not promises of success. Start with a bounded claim whose output can be checked independently, then prove the normalization before claiming an algorithmic improvement. The paper's present genus-one scope should stay stable while extensions develop in separate notes and code.

| Research direction | Existing starting point | Missing result and useful test |
| --- | --- | --- |
| Fast branch-point queries | Current admissible formula excludes f(μ)=0; current fallback streams O(p) work. Katz's first/second-kind Cartier framework and Voloch's ζ analogue were suggested for investigation. | Derive the second-kind replacement including local-coordinate and differential scales. Match direct coefficient expansion on every branch of small squarefree cubics and quartics, then establish the cost. |
| Complete rounded third points for p≡2 mod 3 | Complete p≡1 mod 3 implementation already exists. Sparse cubic supports a related prefix for p≡2 mod 3. | State the integer endpoint precisely, derive the boundary coefficient, and determine whether CM trace data suffices. Test prefix and boundary separately before reporting complete U timings. |
| Further genus-one stopping families | Sparse cubic/quartic models already explain the third and quarter cases. | Identify the exact supported exponents and endpoint, then prove the coefficient identity and boundary recovery. Degree alone does not prove that an arbitrary truncation is represented by the same curve. Half-point prefixes can be trivial full binomial sums; inspect that before proposing a new Miller application. |
| Cheap higher-genus boundaries | Restricted maximal-family prefixes and O(g³ log p) prototype already exist in historical/higher_genus_20260928. | Find a_L at the family's specified endpoints with a proven cheap method. Complete cost is O(g³ log p+T_a(p,g)); a fixed-genus logarithmic prefix does not alone imply logarithmic U. Validate both terms of the weighted identity. |
| Fast modulo-p² Cartier–Miller sums | Historical local-lift/Witt computations and complete native Witt/BGS branch are retained. | Extract the missing correction without first computing the original truncated sum. Naive lifting already fails: at p=13 it predicts B=44 rather than B=70 modulo 169. Account for the weighted sequence's additional harmonic correction as well as the prefix correction. |
| Extension-field arguments | The regular Frobenius/Cartier differential mechanism suggests a starting point. | Re-derive the output functional, semilinearity, annihilator, and exceptional cases over F_{p^k}. The base-field equality S(λ)=T(1/λ) uses λ^(p−1)=1 and cannot simply be copied. |
| Faster practical trace preparation | Experimental exact Schoof and point-count BSGS are present in the October 5 GUI. Historical compiled code also accepts PARI ellap. | Integrate an actual optimized trace provider or SEA backend, record its exactness and assumptions, and time complete preparation plus the same queries. This is an implementation extension, not a replacement for the deterministic theorem. |
| Miller arithmetic and batched workloads | Affine differentiated Miller recurrences and resumable quadratic splitting are implemented. | Investigate projective formulas, inversion batching, or genuine many-argument workloads while preserving differential normalization and every exceptional/split path. Compare complete outputs with retained independent methods. |
| Literature and human review | Current proof, source checks, and large finite validations are retained. | Independently verify the exceptional scalar and trace-one identification, pursue citation tracing, and determine what exact formulation is already known. A useful overlap result is worthwhile even if it narrows novelty. |

The first two directions are bounded genus-one tasks closest to the current paper. The higher-genus boundary and fast Witt correction are more ambitious. Choosing among them should reflect the desired mathematical question, rather than extending every branch at once.

Uniform fast U_p(L) for all stopping indices would be much stronger than a special-family result. Adjacent values determine central binomial coefficients, and these yield a factorial-halving reduction. This is a one-way implication, not a lower bound or proof of impossibility. None of the retained work establishes a decimal BBP formula, a factoring algorithm, or an automatic higher-modulus result.

A p-adic lift of the local Miller coefficient is a well-defined research object after specifying a good-reduction lift and torsion lift, but it is not the usual elliptic group logarithm, which vanishes on torsion. Higher-precision coefficients alone do not establish higher-precision truncated sums. The historical p-adic report gives a concrete failed naive lift and slower correction formulas that should be read before starting this task.
