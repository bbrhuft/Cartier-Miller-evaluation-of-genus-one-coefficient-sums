# Research ledger: CM-to-Cartier comparison and the D = −7 seed (revision 1)

12 October 2026. Revised after independent adversarial review (see `REVIEW_RESPONSE.md`); the reviewed version is in `history/`. This is a separate ledger for the extension note `CM_Cartier_Extension_Note_20261012.md`. The manuscript, the earlier ledgers and the retained code are preserved unchanged.

| Field | Record |

| Question | Is β/H ≡ −(3B/2A)·s₂(τ) (mod 𝔭) correct in the project's normalization? Can exact fixed-discriminant CM data give the coefficient directly? Can one new class-number-one seed (D = −7 preferred) be certified with an original-cubic evaluator? |
| Answer | **Yes** to all three, within the stated hypotheses. The comparison holds with the displayed sign and constants (Theorem 5). All six retained families follow from it at every eligible prime (Theorem 6). The D = −7 seed is certified (Theorems 7–8), with D = −8 as a control (Proposition 9). |
| Main derivation | (1) Characteristic p: Cartier commutes with a separable F_p-endomorphism, so β(λ−μ) = νH (Theorem 1). (2) The de Rham matrices of normalized isogenies, isomorphisms and automorphisms are characteristic-free (Lemma 2), which gives β/H = σ_G/(ℓ−u²). (3) Characteristic 0: the quasi-period law G₂\*(Λ′) = ℓG₂\*(Λ) + σ_G gives G₂\*(Λ) = σ_G/(a(a−ā)) = c, and G₂\*·A/B = (3/2)s₂. (4) Reducing the explicit chain modulo 𝔓 identifies the two (Theorem 5). |
| Unit-root line | Interpretation only, not used in the proofs. U ⊗ F_p = Im(φ mod p) = Im F\* = ker 𝒞_dR = ⟨[η] − (β/H)[ω]⟩, using canonical low-order primitives. The conventions are stated, and V = 𝒞 is never used. |
| Characteristic-p warning | Second-kind differentials modulo exact forms form a one-dimensional space (≅ H⁰(Ω¹) via 𝒞). On ordinary curves, η − (β/H)ω is exact, with primitive G(x)/yᵖ. This primitive was exhibited and checked exactly. So the "de Rham matrix" exists only through characteristic-free formulas or the canonical-primitive convention. |
| Prior art (added) | Katz (2019, *On a question of Zannier*, Thm 3.1) gives H ≡ E_{p−1} and β ≡ E_{p+1}/12, with no common zero, for every curve; β/H is the unit-root direction (P/12). Checked exactly in this chart on 7,948 models. At ordinary CM points, Katz (1976) gives the algebraic E₂\* value. So the comparison is classical, and s₂ = 5/21 for D = −7 is published (Sutherland's γ table, γ = 181/637875). |
