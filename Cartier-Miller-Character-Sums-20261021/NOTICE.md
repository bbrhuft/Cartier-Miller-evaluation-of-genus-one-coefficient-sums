# Provenance and repository integration

This is research code and data prepared for David Jordan's Cartier–Miller project. Preserve the destination repository's applicable license and attribution conventions when integrating the new project files. No separate license for the manuscript or third-party material is invented by this handover.

The retained cm_system dependency in historical_benchmark/inherited/character_sums/vendor/ has the accompanying MIT notice cm_system_LICENSE, copyright 2026 David Jordan. Keep that notice with retained copies. Its original provenance is recorded in the inherited module docstring and reports. The historical native C source and tiny Linux shared-library snapshot are retained so the frozen benchmark can be identified; the current standard-library evaluator does not load that binary.

External benchmark libraries are runtime dependencies, not bundled replacements. The final archive omits third-party source-paper full texts, cached bytecode, local upload helpers and incomplete temporary files. Mathematical constructions from the literature remain attributed in the paper and source guide. The handover itself makes no change to a remote repository or public release.
